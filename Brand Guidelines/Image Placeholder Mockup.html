How to read this file

Every dashed box is an open slot. The orange tag above a section is its Slot ID — cross-reference it in the Image Placement Sheet for the full brief, licensing notes and Harbour treatment rules (navy scrim, radius, alt-text convention).

Sizes shown are the minimum source resolution to deliver — double the on-screen size, so images stay sharp on retina displays. Everything else on this page (type, colour, buttons, layout) is the real, shipped design — nothing here needs sign-off except the images themselves.
